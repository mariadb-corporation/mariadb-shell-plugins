# The test dependencies. run_tests.py installs them into a folder of its own
# and puts it on PYTHONPATH for the run; never install them into the shell's
# own site-packages (mariadb-shell --pym pip install ...): pip may then replace
# a package the shell bundles with a version that breaks it. The packages the
# plugin needs at run time come with the shell and are not listed here.

# pytest 7.0 crashes on the shell's Python 3.14 (its assertion rewriter uses
# ast.Str, removed in Python 3.12), so the floor is the oldest release verified
# to work. Left open at the top end - 7.4, 8.4 and 9.1 all pass the suite.
pytest >= 7.4
pytest-cov >= 2.10.1
